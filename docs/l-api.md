# l.1ms.dog：看访客实际用的是哪个解析器

`l.1ms.dog` 是 1ms.dog 自己的权威 DNS（`server/dns`，在东京）。浏览器解析这个区下的一个随机名字时，来查询的就是访客实际用的那个解析器（或者是浏览器自己的安全 DNS），所以它能看到这个解析器的出口地址，以及解析器有没有把访客的网段（ECS）转交过来。dns.1ms.dog 用它显示「你的设备实际在用的 DNS」和每家「为你服务的节点」；1ms.dog 的其他工具也在用。

## 用法

1. 每次检测在浏览器里生成新的随机 token：8–32 位 `[a-z0-9]`，建议 16 位以上。
2. 让浏览器解析 `<token>[-<tag>].l.1ms.dog`。最简单的写法是 `fetch("https://<token>-<tag>.l.1ms.dog:2053/")`：
   - 这个名字解析到本服务器，2053 端口有 `*.l.1ms.dog` 的证书，返回的就是下面的 JSON，带 CORS。一次请求既让浏览器做了解析，又拿回了结果。
   - 不要连 443 端口，那是这台机器上别的服务。
   - `tag` 是 1–16 位 `[a-z0-9]`，和 token 之间用一个 `-` 连成同一级标签（不能写成多级，否则会被 QNAME 最小化拆开），用来区分同一个 token 下的不同查询。
3. 也可以单独取：`GET https://api.l.1ms.dog:2053/t/<token>[?wait=毫秒&settle=毫秒]`
   - 没有记录时，最多等 `wait`（默认 1500，上限 5000）。
   - 收到第一条后，再等 `settle`（默认 600，上限 3000）才返回。A 和 AAAA 两条查询都要收进来；有的解析器（中国联通）先发一条不带 ECS 的查询，约 250 ms 后才从别的地址发带 ECS 的。
4. 经某家 DoH 查：向这家的 DoH 发 `<token>-<tag>.l.1ms.dog` 的查询（不用读它的应答），记录里会出现这家为这位访客服务的出口节点，以及它带没带 ECS。
5. 能不能走 IPv4 或 IPv6：`<token>-<tag>.v6.l.1ms.dog` 委派给只有 AAAA 记录的 `ns6.l.1ms.dog`，解析器只有能走 IPv6 才拿得到答案，所以出现 `zone:"v6"` 的记录就说明它能走 IPv6；`v4.l.1ms.dog` 同理。v6 区只应答 AAAA，v4 区只应答 A。这两个区不在通配证书范围内，结果要用 `api.l.1ms.dog` 取。
6. 命令行：`dig TXT whoami.l.1ms.dog` 返回 `"resolver=<IP>" "ecs=<网段>"`。

## 返回格式

```json
{"token":"…","hits":[…],"geo":"IP geolocation by DB-IP (https://db-ip.com), CC BY 4.0"}
```

`hits` 一定是数组，没有记录时是 `[]`。页面上展示 `cc`、`asn`、`org` 时，要带上 `geo` 这句署名（DB-IP 的许可要求）。

每条 hit 的字段：

| 字段 | 内容 |
|---|---|
| `tag` | 名字里 `-` 后面的部分，没有就是 `""` |
| `zone` | `"l"`、`"v4"` 或 `"v6"` |
| `ip` | 来查询的解析器的出口地址 |
| `family` | 4 或 6 |
| `proto` | `"udp"` 或 `"tcp"` |
| `qtype` | A、AAAA、TXT、NS… |
| `ecs` | 解析器转交来的 EDNS Client Subnet，比如 `"203.0.113.0/24"`；没带就没有这个键 |
| `n` | 相同查询的次数 |
| `ms` | 距这个 token 第一条查询的毫秒数 |
| `asn`、`org`、`cc` | 网络号、机构、所在国家（两位大写字母）；查不到就没有这些键 |

## 怎么判断带没带 ECS

按 `ms` 排序后，看最先到的那条：浏览器用的是它的答案。

- 最先到的带了：算带。
- 都没带：不带。
- 最先到的没带、后来的带了：如实说「最先的查询没带你的网段，稍后的几条带了」。后来那几条通常来自同一网络里的其他地址，不是同一个解析器，所以对按 DNS 分配节点的 CDN，不能据此下结论。

## 隐私和限制

- 每个 token 的记录只在内存里保留 2 分钟，不写盘，不写日志，最多记 32 条不同的查询。
- 解析器 IP 和 ECS 网段只显示给访客本人看，不进分享链接、分享卡片和体检 facts。ECS 就是访客自己 IP 所在的那一段，比解析器 IP 更敏感。
- UDP 按来源前缀限速（RRL），只做权威，不做递归，区外的查询一律 REFUSED。
