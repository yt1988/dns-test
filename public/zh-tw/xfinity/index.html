說明

Xfinity DNS 是什麼？

Xfinity DNS 是 Comcast 提供的免費公共 DNS，營運單位位於美國。它只提供加密 DNS（DoH），沒有公開的一般 DNS 位址。它主要服務美國：離得近時可能是最快的，離得遠通常不如全球性的大型服務。

它會驗證 DNSSEC（網域簽章）：簽章對不上的回應會被拒絕，可以防止偽造。它不做任何過濾，所有網域都照常解析。

Xfinity DNS 伺服器位址

使用 Xfinity DNS 時，請填入：

DoH https://doh.xfinity.com/dns-query

Xfinity DNS 設定方式

Windows 11

Windows 要先填一般 DNS 位址才能使用加密 DNS，而 Xfinity DNS 沒有公開這種位址。可以在瀏覽器裡使用（見下文），或安裝 dnscrypt-proxy 之類的本機 DNS 用戶端。

macOS

macOS 透過描述檔使用加密 DNS：安裝一個指向 https://doh.xfinity.com/dns-query 的 DNS 描述檔即可。

iPhone 和 iPad

安裝一個指向 https://doh.xfinity.com/dns-query 的 DNS 描述檔，再到設定 → 一般 → VPN 與裝置管理 → DNS 開啟。

Android

Android 上沒有地方能直接設定它：Xfinity DNS 既沒有 DoT 主機名稱，也沒有一般 DNS 位址。請在瀏覽器裡使用。

路由器

路由器只能填一般 DNS 位址，而 Xfinity DNS 沒有公開這種位址。OpenWrt 可以用 https-dns-proxy 轉送到 https://doh.xfinity.com/dns-query。

瀏覽器

Chrome：設定 → 隱私權和安全性 → 安全性 → 使用安全 DNS → 自訂，填入 https://doh.xfinity.com/dns-query。Edge 的相同選項在「隱私權、搜尋與服務」裡。Firefox：設定 → 隱私權與安全性 → DNS over HTTPS → 最大保護 → 自訂，填入 https://doh.xfinity.com/dns-query。

在中國大陸能用 Xfinity DNS 嗎？

一般 DNS 通常能用，但伺服器在中國大陸以外，速度會慢一些，而且被封鎖網站的回應可能在途中遭到偽造。加密 DNS（DoH、DoT）經常連不上或不穩定。最簡單的方法是在本頁測一下：如果結果顯示「從你的網路連不上它」，就代表你的網路連不上它。

Xfinity DNS 和 Google Public DNS 哪個快？

沒有哪一家在任何地方都比較快。關鍵在於兩家離你最近的伺服器有多遠，以及你的電信業者走哪條線路過去。本頁幾秒鐘就能從你自己的網路測出 Xfinity DNS 的速度；想和其他 DNS 比較，請用首頁的測試，它會把清單裡的每一家都測一遍，告訴你哪家最快。

為什麼 Xfinity DNS 在我這裡很慢？

最常見的原因是距離：離你最近的伺服器也很遠，或是電信業者繞了遠路。開著代理或 VPN 時，查詢也會經過代理，測到的是代理的線路，加上直連規則就能測準。有些網路會限速或阻擋加密 DNS。另外，還沒人查過的網域一定比較慢（見結果下方的首次查詢時間）。想知道有沒有更快的，用首頁的測試把全部 DNS 測一遍。

要怎麼更改 DNS？

Android 9 以上：設定 → 網路 → 私人 DNS，填入 DoT 主機名稱（例如 one.one.one.one）。所有網路都有效，而且是加密的。

iPhone 和 Mac：在每個 Wi-Fi 的設定裡填 DNS 伺服器；要使用加密 DNS，請從 DNS 官網下載並安裝描述檔。

Windows 11：設定 → 網路 → 目前的連線 → DNS 伺服器指派 → 手動，填入位址，再開啟 DNS over HTTPS。

路由器：在 DHCP 或 WAN 設定裡填 DNS 伺服器，家中所有裝置都會用上。

只改瀏覽器：Chrome、Edge、Firefox 都有「安全 DNS」設定，可以選一家或貼上 DoH 位址。

每家 DNS 的專頁都有逐步的設定方式。點頁面上任何一個位址就能複製。

開著代理，測出來的還是我的網路嗎？

預設不是。開著代理或 VPN 時，瀏覽器會經由代理連到各家 DNS，測到的是代理的線路，境外的 DNS 都會顯得和代理伺服器差不多快。而你在裝置或路由器上設定的 DNS，平常通常是直接連線的，所以這個數字不是你實際使用時的速度。

想測自己的網路，就加上直連規則（進度列旁邊的按鈕）。規則只讓這個測試用到的位址直連，以精確的網域名稱和單一 IP 比對，不影響其他流量。支援 Clash/Mihomo、Surge、Shadowrocket、Quantumult X、Loon、sing-box 和 Xray，多數可以直接從本站載入規則集，自動保持最新。

測試是怎麼進行的？

你的瀏覽器直接向每家 DNS 送出查詢，不經過本站。

先和它建立連線，把三個熱門網域各查一次，讓它們進入它的快取，這一步不計分。接著測 10 輪，每輪查一次，這樣網路偶爾卡一下也不會左右結果。每隔一輪還會查一個根本不存在的隨機網域。

結果取中位數，偶爾一次變慢不會拉低成績。時間採用瀏覽器自己記錄的網路耗時，頁面程式拖不慢它。每次請求的網址都不同，而且繞過所有快取，只能由 DNS 伺服器本身回答。

為什麼 UDP 和 DoT 是估算的？

因為瀏覽器做不到。網頁只能送出 HTTPS 請求：一般 DNS 使用的 UDP（53 埠）、加密的 DoT（853 埠）和 DoQ，它都送不出去。沒有任何網站能從你的網路測這些；顯示這類數字的網站，不是在自己的伺服器上測的，就是用猜的。

這個頁面的做法是：向負責 UDP 和 DoT 的同一台伺服器送出 DoH，也就是透過 HTTPS 加密的 DNS 查詢（例如 https://1.1.1.1/dns-query）。連線建立後，一次查詢的耗時就是到這台伺服器跑一趟來回，再加上它處理的時間。UDP、DoT 查詢花的也正是這些，HTTPS 這一層多出不到 1 毫秒，所以標成 ≈。一般 DNS 伺服器不支援 HTTPS 的幾家，會顯示 –，不會硬湊數字。

估算看不出來的狀況：有些網路會單獨封鎖、限速或竄改 53、853 埠，而不動 HTTPS。

要實測 UDP、DoT 和 DoQ，請在伺服器、Linux 主機或路由器上執行本頁命令列框裡的那行指令。它支援所有協定，會測這家 DNS 和與它比較的那一家。

結果可靠嗎？

測量方式請見「測試是怎麼進行的？」。此外，DNS 清單用程式碼庫裡的 scripts/verify.mjs 在多個大洲核實過：每個位址都必須對這種查詢回傳真正的 DNS 回應；DNSSEC 是實際測出來的，不是照抄各家的宣傳。

Cloudflare、Google、Quad9、Control D、DNS.SB、DNS4EU、IIJ 這幾家允許網頁讀取回應內容，頁面會逐筆檢查，只計入真正的回應。其他幾家瀏覽器只能計時，看不到內容。

建議多測幾次，最好換不同時段：晚上最快的，尖峰時段不一定最快。

「首次查詢」是什麼意思？

熱門網域早就在各家 DNS 的快取裡，查起來哪一家都快。很久沒人查過的網域就不同了：DNS 伺服器得先去問這個網站自己的 DNS 伺服器，再把答案告訴你，這就是「首次查詢」。

測試用的是託管在 Cloudflare 上的隨機網域，Cloudflare 的 DNS 伺服器除了中國大陸，幾乎遍布全球。這部分的耗時取決於每個網站的 DNS 伺服器在哪裡，各不相同，所以只顯示、不排名。中國大陸的 DNS 在這裡的首次查詢顯得慢，是因為這些網域的伺服器在境外；查詢中國大陸的網站時，它們很快。

DNSSEC 是什麼？

簡單說，就是網域替自己的 DNS 紀錄加上簽章，避免被偽造。會驗證 DNSSEC 的 DNS 伺服器會檢查簽章，對不上就拒絕，這樣途中誰都沒辦法塞給你假位址。有 ✓ 的就是會驗證的：我們用一個故意簽錯的網域 dnssec-failed.org 來測試，它們必須拒絕。它只對有簽章的網域有效，但開著沒有壞處。

ECS 是什麼？為什麼這裡沒有顯示？

ECS（EDNS Client Subnet）是指 DNS 伺服器把你 IP 位址的一部分轉告給網站的 DNS 伺服器，讓 CDN 依你的位置、而不是 DNS 伺服器的位置分配伺服器。下載和影片可能更快，代價是多透露一點你的所在位置。

這裡沒有顯示它，因為它不是固定的：我們核實時發現，同一家 DNS 在某些地方、某些協定會傳，換個地方或協定又不傳。只寫「是」或「否」都會誤導你。

為什麼沒有 114DNS、百度 DNS？

它們只提供一般 DNS，伺服器完全不回應 HTTPS，瀏覽器沒有任何方法連上，所以無法測試。中國台灣的 Quad101 也沒有收錄：我們核實時，它的 DoH 從其他地區連不上。

會收集我的資料嗎？

不保存測試結果，也不保存任何關於你的資訊。測試的查詢從你的瀏覽器直接送到各家 DNS，查的是熱門公共網站和隨機網域，裡面沒有關於你的資訊。結果只留在你的瀏覽器裡；只有點「分享」時才寫進分享連結（每家 DNS 的耗時，不含 IP 位址；要不要帶上你所在的國家或地區由你決定）。

有一件事會經過 1ms.dog 自己的伺服器（在東京）：為了顯示你的裝置實際在用哪個 DNS，頁面會查一個 l.1ms.dog 底下的隨機網域，這個網域的 DNS 伺服器是我們的；測完後還會經每家 DNS 各查一個這樣的網域，看是它的哪個節點在為你服務。這台伺服器能看到來查詢的 DNS 的位址，以及這家 DNS 轉交過來的你的網段（ECS：你 IP 位址的前半部分，例如 203.0.113.0/24）。它只在記憶體裡保留 2 分鐘，供頁面從 api.l.1ms.dog 取回，之後就丟棄，不寫入磁碟，也不寫日誌。這些資訊只顯示給你自己，不會進分享連結和分享卡片。

和所有 DNS 查詢一樣，各家 DNS 會看到你的 IP 位址，適用它們各自的隱私政策。程式碼在 GitHub 開源。
