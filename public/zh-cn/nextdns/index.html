帮助

NextDNS 是什么？

NextDNS 是 NextDNS 运营的免费公共 DNS，运营方在美国。普通 DNS 地址是 45.90.28.0、45.90.30.0（IPv6：2a07:a8c0::、2a07:a8c1::），也支持加密 DNS：DoT、DoH、DoQ。它的服务器分布在全球多地，查询会发到离你最近的一台。

它验证 DNSSEC：签名对不上的应答会被拒绝。它不做过滤，所有域名照常解析。注册免费账号可以自定义拦截列表、查看查询记录；不注册也能直接用公共地址。

NextDNS 的 DNS 服务器地址

使用 NextDNS 时填写：

DNS (IPv4) 45.90.28.0、45.90.30.0

DNS (IPv6) 2a07:a8c0::、2a07:a8c1::

DoT / 私人 DNS dns.nextdns.io

DoH https://dns.nextdns.io/

DoQ quic://dns.nextdns.io

NextDNS 怎么设置

Windows 11

设置 → 网络和 Internet → WLAN 或以太网 → 硬件属性 → DNS 服务器分配 → 编辑 → 手动。打开 IPv4，填入 45.90.28.0、45.90.30.0。要加密的话，把「DNS over HTTPS」设为「开（手动模板）」，模板填 https://dns.nextdns.io/。

macOS

系统设置 → 网络 → Wi‑Fi（或以太网）→ 详细信息 → DNS，点 + 添加 45.90.28.0、45.90.30.0。加密 DNS（https://dns.nextdns.io/）需要安装描述文件。

iPhone 和 iPad

设置 → 无线局域网 → 网络旁的 ⓘ → 配置 DNS → 手动，添加 45.90.28.0、45.90.30.0。只对这个 Wi‑Fi 生效；想在所有网络上用加密 DNS，安装一个指向 https://dns.nextdns.io/ 的 DNS 描述文件。

安卓

设置 → 网络和互联网 → 私人 DNS → 私人 DNS 提供商主机名，填 dns.nextdns.io。在所有网络上生效，并且是加密的（DoT）。各品牌菜单位置略有不同，可在设置里搜索「私人 DNS」。

路由器

进入路由器管理页面（WAN 或 DHCP 设置），把 DNS 服务器改成 45.90.28.0、45.90.30.0：局域网里的所有设备都会用它。

浏览器

Chrome：设置 → 隐私和安全 → 安全 → 使用安全 DNS → 自定义，填 https://dns.nextdns.io/。Edge 在「隐私、搜索和服务」里有同样的选项。Firefox：设置 → 隐私与安全 → 基于 HTTPS 的 DNS → 最大保护 → 自定义，填 https://dns.nextdns.io/。

Linux

使用 systemd-resolved 时：在 /etc/systemd/resolved.conf 里写 DNS=45.90.28.0 45.90.30.0，再运行 systemctl restart systemd-resolved。要用 DoT，把地址写成 45.90.28.0#dns.nextdns.io，并加上 DNSOverTLS=yes。

NextDNS 在中国大陆能用吗？

普通 DNS 一般能应答，但服务器在境外，延迟更高，被封锁网站的应答还可能在途中被伪造。到它的加密 DNS（DoH、DoT）经常被阻断或不稳定。在本页测一下：某一行没有应答，就说明从你的网络连不上它。

NextDNS 和 AdGuard DNS 哪个快？

没有哪个在所有地方都更快：关键是两家离你最近的服务器有多远、你的运营商怎么走到那里。本页大约 20 秒就能从你自己的网络把两家连同列表里的其他 DNS 都测一遍；页面顶部会显示 NextDNS 排第几、比最快的慢多少。

为什么 NextDNS 对我来说很慢？

通常是距离：离你最近的服务器很远，或者运营商绕了远路。开着代理或 VPN 时，查询也走代理，测出来的是代理的线路（加上直连规则就好）。有些网络会限速或阻断加密 DNS。另外，没人查过的域名总是更慢（见「未缓存」一列）。如果列表里有明显更快的 DNS，换成它就好。

测试是怎么进行的？

你的浏览器直接向每家 DNS 发查询，不经过本站。先和每家建立连接，把三个热门域名各查一次，让它们进入这家 DNS 的缓存，这一步不计入结果。然后测 10 轮：每轮把每家各查一次，顺序重新打乱，几家同时进行，所以网络偶尔卡一下，影响的是所有 DNS，而不是刚好在测的那一家。每隔一轮还会查一个根本不存在的随机域名。

结果取中位数，个别一次慢不会影响数字。时间取自浏览器自己记录的每个请求的网络耗时，页面脚本拖不慢它。每个请求的地址都是新的，并且绕过所有缓存，只有 DNS 本身能回答。

为什么 UDP 和 DoT 是估算？

浏览器只能发 HTTPS 请求，发不了 53 端口的 UDP 查询，也连不了 853 端口的 TLS（DoT），更不支持 DoQ。任何网站都没法从你的网络测这些。显示这类数字的网站，要么是在它自己的服务器上测，要么是猜的。

页面能做的是：向负责 UDP 和 DoT 的同一台服务器发 DoH（比如 https://1.1.1.1/dns-query）。在已建立的连接上，一次查询的耗时等于到这台服务器的一个往返加上解析器的处理时间，UDP 和 DoT 查询花的也正是这些，HTTP 本身只多不到 1 毫秒，所以标成 ≈。普通 DNS 服务器不支持 HTTPS 的那几家，显示 –，不硬给数字。

估算看不到的情况：有的网络会封锁、限速或篡改 53、853 端口，但不动 HTTPS。

要实测 UDP、DoT 和 DoQ，在服务器、Linux 主机或路由器上运行命令行工具（表格下方那条命令）：它支持所有协议，测的是同一份 DNS 清单。

结果可靠吗？

测量方法见第一条。另外，清单用仓库里的 scripts/verify.mjs 在多个大洲核实过：每个地址都必须对这种查询返回真正的 DNS 应答；DNSSEC 是实际测出来的，不是照搬各家的宣传。

允许读取应答的几家（Cloudflare、Google、Quad9、Control D、DNS.SB、DNS4EU、IIJ），页面还会逐条检查应答，只统计真正的应答。其他几家浏览器只能计时，读不到内容。

建议多测几次，最好换个时间段：晚上最快的，高峰期不一定最快。

开着代理，测出来的还是我的结果吗？

默认不是：开着代理或 VPN 时，浏览器经过代理去连各家 DNS，测到的是代理的线路（境外的 DNS 都会显得和代理服务器差不多快）。而你在设备或路由器上设置的 DNS，平时一般是直接访问的，所以这不是你实际会得到的速度。

要测自己的网络，加上直连规则（进度条旁边的按钮）：只把这个测试访问的地址设成直连，按精确的主机名和单个 IP 匹配，不影响其他流量。支持 Clash/Mihomo、Surge、Shadowrocket、Quantumult X、Loon、sing-box 和 Xray，多数可以从本站拉取规则集，自动保持最新。

「未缓存」是什么意思？

热门域名早就在各大 DNS 的缓存里，查起来哪家都快。很久没人查过的域名，DNS 得先去问网站自己的 DNS 服务器。测试用的是一个托管在 Cloudflare DNS 上的区域下的随机域名，Cloudflare 的服务器除了中国大陆，几乎遍布全球。

这部分耗时取决于每个网站的 DNS 服务器在哪，各不相同，所以只显示，不参与排名。国内的 DNS 在这里显得慢，是因为这个区域的服务器在境外；查国内网站（DNS 服务器在国内）时它们很快。

该选哪一个？

排在最上面的一般就是好选择。如果几家差不多（相差几毫秒），按你在意的其他方面选：Quad9 和 OpenDNS 会拦截已知的恶意和钓鱼网站；Mullvad、Quad9 和 Wikimedia 不记录谁查了什么；验证 DNSSEC 的 DNS 会拒绝签名域名的伪造应答。

如果设备只能填普通 DNS 服务器地址（大多数路由器、较老的系统），看 UDP 那一列：最快的普通 DNS 如果不是第一名，会写在第一名下面那行。

不想让所在网络和运营商看到你查了什么，就用 DoT 或 DoH 地址：普通 DNS 是明文传输的。

怎么修改 DNS？

安卓 9 以上：设置 → 网络 → 私人 DNS → 填 DoT 主机名（比如 dns.alidns.com）。

iPhone 和 Mac：在每个 Wi-Fi 网络里填 DNS 服务器；要用加密 DNS，从 DNS 官网安装描述文件。

Windows 11：设置 → 网络 → 当前连接 → DNS 服务器分配 → 手动，填入服务器，并打开 DNS over HTTPS。

路由器：在 DHCP 或 WAN 设置里填 DNS 服务器，网络里所有设备都会用上。

只改浏览器：Chrome、Edge、Firefox 都有「安全 DNS」设置，选一家或粘贴 DoH 地址。

点页面上任何一个地址即可复制。

DNSSEC 是什么？

DNSSEC 让域名给自己的 DNS 记录签名。验证 DNSSEC 的 DNS 会检查签名，对不上就拒绝，这样途中谁也没法给你一个签名域名的伪造地址。页面上打 ✓ 的就是会验证的（用一个故意签错的域名 dnssec-failed.org 测试，它们必须拒绝）。只对签了名的域名有用，但没有坏处。

为什么没有 114DNS、百度 DNS？

它们只提供普通 DNS，服务器完全不响应 HTTPS，浏览器没有任何办法连到它们。台湾的 Quad101 也没收录：我们核实时，它的 DoH 在境外连不上。

ECS 是什么？为什么不显示？

EDNS Client Subnet：有的 DNS 会把你的部分 IP 地址告诉网站的 DNS 服务器，这样 CDN 能按你的位置而不是 DNS 的位置分配服务器，下载和视频可能更快，代价是隐私上少一点。

表格里不显示它，因为它不是固定属性：我们核实时，同一家 DNS 从有的地方、走有的协议会传，换个地方、换个协议又不传，给一个「是」或「否」都会误导。

会收集我的数据吗？

不会。查询从你的浏览器直接发给各家 DNS，查的是公开的热门网站和随机域名，不含任何你的信息。本站收不到测试结果。和平时的任何 DNS 查询一样，各家 DNS 能看到你的 IP 地址，适用它们各自的隐私政策。代码在 GitHub 上开源。
